# 让 Claude 审查（只读）

1. 先确认 Claude 命令行可用：运行 `claude --version`。不可用就告诉用户“电脑上没有 claude 命令”，并停止，不要自己编造 Claude 的意见。
2. 如果你本身就是被 Claude 调用来审查的，不要使用这个 skill。
3. 运行下面的命令（计划模式，Claude 只能读不能改）。把引号里的要求按用户的需求调整，但不要在引号内放英文双引号、`$` 或反引号，以免在 PowerShell 里被转义：

   ```
   claude -p --permission-mode plan "审查当前仓库未提交的改动，请自己运行 git status 和 git diff 查看，只读不要修改任何文件。重点：bug、遗漏的边界情况、与 PLAN.md 不一致的地方。按 必须改 和 可选 两类列出，每条附文件名和行号。"
   ```

4. 把 Claude 的输出转述给用户，开头标明“以下来自 Claude”。对每一条说明你是否同意以及理由，不要不加判断地照做。
5. 没有用户同意，不要根据 Claude 的意见直接改文件。
6. 如果命令报错（没登录、没配置中转站地址、额度用完、超时），把原始错误告诉用户，不要重试超过一次。
